# Monetization-Pressure-Index

Monetization Lens is an open-source project that makes video game monetization systems transparent and comparable by analyzing transaction types and monetization pressure mechanics through a reproducible 0–100 

The project introduces the **Monetization Pressure Index (MPI)** — a reproducible 0–100 score that combines:

- how widespread different transaction types are among players;
- how strongly a game uses monetization pressure mechanics.

The goal is not to label games as “good” or “bad”, and not to diagnose addiction.  
The goal is to make complex monetization systems easier to inspect and compare using transparent rules, open data, and a reproducible methodology.

---

## Why this project exists

Modern games use many different monetization systems:

- virtual currencies;
- cosmetics;
- battle passes;
- loot boxes and gacha;
- subscriptions;
- progression boosts;
- resources;
- equipment;
- paid convenience features;
- DLC and expansions.

The problem is that these systems are often difficult to compare.

Two games may both contain in-game purchases, but one may use only cosmetic purchases while another may combine:

- limited-time offers;
- randomized rewards;
- virtual currencies;
- progression barriers;
- personalized offers;
- competitive advantages.

A simple label such as “contains in-game purchases” does not show this difference.

Monetization Lens aims to create a transparent standard for describing that difference.

---

# Project Goal

The main goal of Monetization Lens is:

> **To make hidden and complex video game monetization mechanics transparent, comparable, and understandable.**

The project shows:

1. what types of transactions exist in a game;
2. how important those transaction types are based on real-world player data;
3. what pressure mechanics the game uses;
4. how these components combine into one reproducible Monetization Pressure Index.

---

# Monetization Pressure Index

The MPI is designed as a score from:

**0 to 100**

A higher score means that the game combines:

- a larger share of important monetization types;
- stronger monetization pressure mechanics.

The model contains two main components:

1. **Transaction Weight**
2. **Pressure Score**

These are combined into the final MPI.

---

# Transaction Weight

**Transaction Weight (TW)** represents how popular each type of in-game transaction is among players.

The weights are based on real player-behavior data and show the relative importance of different transaction types.

---

# Pressure Score

**Pressure Score (PS)** represents how strongly a game uses monetization pressure mechanics.

It evaluates the overall monetization pressure of the game using a consistent set of predefined and reproducible rules.

---

# Data and Methodology

Monetization Lens is based on:

- external market and player-behavior research;
- scientific studies;
- structured analysis of real video games;
- original collected data;
- predefined evaluation rules.

The methodology is designed so that every result can be traced back to the data and rules used to produce it.

# Индекс монетизационного давления

Monetization Lens — это проект с открытым исходным кодом, который делает системы монетизации в видеоиграх прозрачными и сопоставимыми, анализируя типы транзакций и механики монетизационного давления с помощью воспроизводимого показателя по шкале от 0 до 100.

Проект вводит **Monetization Pressure Index (MPI)** — воспроизводимый индекс от 0 до 100, который объединяет:

- насколько широко различные типы транзакций распространены среди игроков;
- насколько активно игра использует механики монетизационного давления.

Цель проекта — не делить игры на «хорошие» и «плохие» и не диагностировать зависимость.  
Цель — сделать сложные системы монетизации более понятными и удобными для анализа и сравнения с помощью прозрачных правил, открытых данных и воспроизводимой методологии.

---

## Зачем нужен этот проект

Современные игры используют множество различных систем монетизации:

- виртуальные валюты;
- косметические предметы;
- боевые пропуски;
- лутбоксы и гача-механики;
- подписки;
- ускорители прогресса;
- ресурсы;
- экипировку;
- платные функции удобства;
- дополнения и расширения.

Проблема заключается в том, что такие системы часто трудно сравнивать.

Две игры могут содержать внутриигровые покупки, однако в одной могут продаваться только косметические предметы, а другая может одновременно использовать:

- ограниченные по времени предложения;
- случайные награды;
- виртуальные валюты;
- искусственные ограничения прогресса;
- персонализированные предложения;
- игровые или соревновательные преимущества.

Простая отметка «содержит внутриигровые покупки» не показывает эту разницу.

Monetization Lens стремится создать прозрачный стандарт для описания таких различий.

---

# Цель проекта

Главная цель Monetization Lens:

> **Сделать скрытые и сложные механики монетизации в видеоиграх прозрачными, сопоставимыми и понятными.**

Проект показывает:

1. какие типы транзакций присутствуют в игре;
2. насколько значимы эти типы транзакций с учётом реальных данных о поведении игроков;
3. какие механики монетизационного давления использует игра;
4. как эти компоненты объединяются в единый воспроизводимый Monetization Pressure Index.

---

# Monetization Pressure Index

MPI представляет собой показатель в диапазоне:

**от 0 до 100**

Более высокий результат означает, что игра сочетает:

- большее количество значимых типов монетизации;
- более выраженные механики монетизационного давления.

Модель включает два основных компонента:

1. **Transaction Weight**
2. **Pressure Score**

Они объединяются для расчёта итогового MPI.

---

# Transaction Weight

**Transaction Weight (TW)** — вес транзакции, который отражает популярность каждого типа внутриигровых транзакций среди игроков.

Веса основаны на реальных данных о поведении игроков и показывают относительную значимость различных типов транзакций.

---

# Pressure Score

**Pressure Score (PS)** — показатель того, насколько активно игра использует механики монетизационного давления.

Он оценивает общее монетизационное давление игры с помощью единого набора заранее определённых и воспроизводимых правил.

---

# Данные и методология

Monetization Lens основывается на:

- внешних исследованиях рынка и поведения игроков;
- научных исследованиях;
- структурированном анализе реальных видеоигр;
- собственных собранных данных;
- заранее определённых правилах оценки.

Методология разработана таким образом, чтобы каждый результат можно было проследить до исходных данных и правил, использованных при его расчёте.

---

# Статус проекта

Monetization Lens находится в стадии разработки.

На текущем этапе основное внимание уделяется исследованию монетизации в видеоиграх, формированию набора данных, проверке методологии и разработке первой рабочей версии проекта.
